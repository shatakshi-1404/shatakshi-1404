### 🐍 Contribution Snake

> [!NOTE]
> The animated snake below renders once the [`snk` GitHub Action](https://github.com/Platane/snk) is set up on this repo — it eats your real contribution graph and regenerates automatically on a schedule.

<div align="center">
<img src="https://raw.githubusercontent.com/shatakshi-1404/shatakshi-1404/output/github-contribution-grid-snake.svg" width="100%"/>
</div>

<details>
<summary>⚙️ One-time setup (workflow file)</summary>

```yaml
# .github/workflows/snake.yml
name: generate snake
on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch: {}
  push:
    branches: [ main ]

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: shatakshi-1404
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
