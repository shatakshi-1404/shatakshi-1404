### 01. Voxera — AI Customer Support & Resolution Agent

<a href="https://voxera-sw58.vercel.app/">
  <img src="https://img.shields.io/badge/Live%20Application-Visit%20Voxera-2563EB?style=for-the-badge&logo=vercel&logoColor=white" />
</a>
<a href="https://github.com/shatakshi-1404/voxera">
  <img src="https://img.shields.io/badge/Source%20Code-GitHub-181717?style=for-the-badge&logo=github&logoColor=white" />
</a>

An AI-powered multilingual customer support system combining **LangGraph agent orchestration, policy-based RAG and deterministic backend tools**.

**Key Engineering Highlights**
- Built a LangGraph support agent integrating LLM-based intent classification and response generation with controlled backend tools.
- Engineered multilingual policy RAG using embeddings, PostgreSQL, pgvector and hybrid retrieval.
- Implemented evidence-grounded responses with automatic escalation when retrieved evidence is insufficient.
- Added customer ownership validation, refund limits and idempotency checks to prevent unauthorized or duplicate transactions.
- Load-tested 10 authenticated endpoints with 100 requests each at concurrency 5: **100% HTTP success**, with **581–698 ms p95 latency** across 7 endpoints.

**Tech Stack:** Python · FastAPI · LangGraph · PostgreSQL · pgvector · Groq · React · TypeScript
